## What we learned (read before migrating more)

- **8 MB OpenCode snapshot**: OpenCode 2.2.6 inlines a models.dev snapshot
  the test runner cannot transfer. Each Vitest config empties it with a
  test-only transform; the probes run OpenCode with `snapshot: false`.
- **Scripted models**: use Miniflare's `outboundService` in the Vitest config
  to answer the Worker's outbound model requests. `createAI` from
  `agents/models/opencode` does not work with OpenCode 2.2.6 here
  ("Npm.add is unavailable in the workerd profile").
- **Crashes**: use `abortAllDurableObjects()`; set `fileParallelism: false`.
- **RPC types**: return small explicit result types from Durable Object
  methods; inferring OpenCode's deep types hits TS2589.
- The dynamic `import("@opencode/sdk/workerd")` works from RPC methods. It
  is untested from alarm or `fetch` handlers, which Cloudflare lists as a
  known issue.
- A mechanical move is roughly size-neutral. Savings come from deleting the
  drivers, Python checks and HTTP dispatch once a suite is fully moved
  (attempt probe: `check.py` 27 KB, `check-purge.py`, the driver script),
  and from removing Python as a test requirement.
