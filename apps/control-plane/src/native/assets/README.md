The application imports `prompt-renderer.bin` as immutable Data and loads it as
Wasm only in a private WorkerLoader child using the existing `LOADER` binding.
Go compilation, runtime and linear memory therefore live outside the native
OpenCode/Workspace isolate. No third deployed Worker or VM is required. The child
has no environment credentials and `globalOutbound: null`.

`wasm_exec.js`, its Text-module copy `wasm_exec.txt`, and `GO-LICENSE` come verbatim
from Go 1.26.5. The child source is a Text module too, so both Wrangler and Vite
load it without special raw-JavaScript rules.

Regenerate from the repository root:

```sh
GO_BIN=/path/to/go1.26.5/bin/go scripts/build-prompt-renderer.sh
GO_BIN=/path/to/go1.26.5/bin/go node scripts/test-prompt-renderer.mjs
```

The build uses `-trimpath`, `-buildvcs=false`, stripped symbols and no C compiler.
`SHA256SUMS` pins identical generated `.wasm`/`.bin` binaries and matching runtime.
`SHA256SUMS.txt` is the Text-module copy used with child sources to derive its
immutable loader cache name. Binary artifacts are ignored and regenerated by
the verified build rather than committed.

The binary calls the original `internal/prompts` and `internal/launchprompt`
packages. Existing embedded immutable assets are compiled without rewriting
prompt bytes or maintaining another rendering implementation. Override parsing,
launch defaults, canonical JSON, wrapper and digest remain original Go behavior.

The workerd test runs all original parity/golden/error/role/concurrency cases
through the actual loader child. It asserts the caller never creates a Go
constructor/callback and records child linear memory. Set
`PENTCLOUD_RENDERER_HEAP_REPORT=1` to collect separate caller/child CDP heap values.
The test's supported local compatibility date defaults to 2026-10-19; the private
child itself uses 2026-08-27. No model or paid service is used by these checks.
